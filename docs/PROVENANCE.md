# Source provenance and publication boundary

First assembled locally on 2026-09-22. Source grouping is recorded in `SOURCE_MANIFEST.json`; content checksums are recorded in `SHA256SUMS`. No training results are included or generated by packaging.

## Source groups

1. **Core:** Python model, loss, data, training/prediction utilities and geometry tests from the existing `icasspcode` package. These retain the historical `c3tta` namespace and supported checkpoint architecture markers. Core training/model/loss code is copied, not rewritten.
2. **Common scorer:** `c3tta/engine/offline_evaluation.py`, `c3tta/engine/evaluation.py`, `c3tta/metrics.py`, and `scripts/score_predictions.py` are copied byte-for-byte from the archived `mechanism_controls_20260922/scoring_source`. This is the common scorer used in the later w/o VRA and SG evaluations. In particular, `offline_evaluation.py` has SHA256 `28cc831a3313bb9182a1b53b2a46a736bc972daec7adebfe5afd107c0ad9a4d0`.
3. **Geometry analysis:** archived `mechanism_controls_20260922/analysis/analyze_predictions.py`, copied without algorithm edits as `scripts/analyze_ratio_geometry.py`. It accepts portable job specifications instead of a fixed server path.
4. **Paper-facing additions:** w/o VRA and stage-2 w/o SG configs, dry-run-first training and four-domain evaluation planners, a strict paper macro aggregator, dependency-free protocol tests, source checks, and current documentation. `docs/DATA.md` started from the core package and was adapted to document the exact backbone initialization. These additions do not create new scientific findings.

The newer mechanism snapshot contains other historical output-construction branches. Those are not copied into the core model, preserving the existing public package's scope. The selected original CP/VRA/ratio/SG paths remain available.

## Kept outside the public directory

No real images/masks, datasets, trained or pretrained weights, real-data manifests, per-image scores, raw predictions, private logs, SSH launchers, IP addresses, credential files, or environment secrets were copied. The geometry-job JSON contains illustrative paths only. Cached/generated artifacts are excluded by `.gitignore`.

The parent collection is preserved as historical material, including its result audits. It is not silently converted into this public repository. This standalone directory is the published repository root.

## Reproduction boundary

- The author selected the MIT License for this source release. Dataset, pretrained-weight, and third-party dependency terms remain separate.
- Update `CITATION.cff` with the final paper URL, DOI, and publication status when available; no acceptance claim has been invented.
- Obtain datasets and DINOv3 weights under their original terms. Weights are not redistributed here.
- Pin a complete environment and verify full runs before claiming exact numerical reproduction. A prepared command or a successful smoke test is not a reproduced experiment.
- This source bundle was assembled without uploading datasets, weights, or per-seed outputs. Its training/evaluation plans should be read as executable protocols, not records of new full runs.
